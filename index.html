ANIMACIÓN 3D

01

Diseño 3D interactivo para web

Este proyecto utiliza Three.js y GSAP para integrar animación 3D en tiempo real, generando una experiencia dinámica y fluida a medida que el usuario navega por la página.

02

Sobre el proyecto

“Bee” es un ejercicio de integración avanzada entre código, diseño y tecnología 3D. El modelo responde al scroll del usuario, adaptando su posición y rotación según la sección visible, ofreciendo una experiencia inmersiva.
