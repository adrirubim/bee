# Contributing

Thanks for your interest in contributing.

## Local verification

Run the repository quality gate from the repo root:

```bash
./scripts/dev-verify.sh
```

## Guidelines

- Keep changes focused and reviewable.
- Do not commit secrets (no `.env`, credentials, tokens).
- If you update `index.html` / `assets/site.webmanifest`, keep all local references consistent (no broken paths).
- Prefer local assets over remote CDNs for production hardening.
